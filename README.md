# Gestion de docentes - Edificio 2, UT Coahuila

Programa en Python que administra numero de empleado, nombre y
especialidad de los docentes, y los exporta a JSON, YAML y XML.

## Uso
python main.py
python -m unittest -v

## Requisitos
Python 3 y la libreria pyyaml (python -m pip install pyyaml)
